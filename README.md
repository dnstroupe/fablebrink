# Fablebrink | Your next world awaits.

Independent streaming UX portfolio project by David Stroupe.

[Live demo](https://dnstroupe.github.io/fablebrink/dist/) | [Case study](https://dnstroupe.github.io/fablebrink/dist/case-study.html) | [Current Figma designs](https://www.figma.com/design/m1JMrEeFiQKkrbcpRGlVE6?node-id=11-69) | [Design handoff](FIGMA-HANDOFF.md)

## Run

`npm start` serves dist at http://localhost:8000. `npm test` runs the source checks. No dependency installation is required.

## Experience

Sixteen fictional titles, eight films and eight series, themed collections, dedicated title URLs, search and combined filters, a saved list, related stories, and two original animated previews with sound. Progress is saved separately for each preview. Muted background motion has a pause control and respects reduced motion.

The train preview is seven seconds; the lunar preview is ten seconds. Full films and episodes are not available. OffbeatPanels entries are proposed treatments.

## Design and review

See DESIGN.md, REQUIREMENTS.md, REVIEW.md, and the case study in dist. Figma: https://www.figma.com/design/m1JMrEeFiQKkrbcpRGlVE6

Twelve automated checks pass. Browser, screen reader, sound and caption, and participant verification remain open. Section 508 compliance has not been established.
